# Toy transcriptome

Generated by `make_toy.py` (fixed seed, so re-running reproduces these files exactly). It
contains three loci and four genes on a synthetic chromosome `toy`, with random exon
sequence and 300–1500 nt introns.

| File | Contents |
| --- | --- |
| `transcripts.fa` | 6 transcripts with GENCODE-style headers (`tx|gene|-|-|tx_name|gene_name|len|biotype|`) |
| `annotation.gtf` | gene, transcript and exon records (1-based, + strand) |
| `genome.fa` | the chromosome (18 kb); GTF exon slices reproduce `transcripts.fa` exactly |

## Splice structure

| Gene | Transcript | Exons (nt) | Event |
| --- | --- | --- | --- |
| GENEA | TOYT0000001 (GENEA-201) | A1 400, A2 250, A3 120, A4 500 | includes cassette exon A3 |
| GENEA | TOYT0000002 (GENEA-202) | A1, A2, A4 | skips A3 |
| GENEB | TOYT0000003 (GENEB-201) | B1 350, B2 300, B3 450 | long B2 |
| GENEB | TOYT0000004 (GENEB-202) | B1, B2[36:], B3 | alternative 3′ splice site: B2 starts 36 nt later |
| GENEC | TOYT0000005 (GENEC-201) | C1 300, C2 400, C3 350 | single isoform |
| GENECP | TOYT0000006 (GENECP-201) | D1, D2, D3 = C1, C2, C3 with 18 substitutions (1.7%) | paralog of GENEC |

## What the index should show

Let h_b be the halo width at the base level: λ_b + ρ_b plus a core length, roughly 20–60 nt
at levels 3–4 (`spearfish locality` measures λ and ρ).

- **GENEA.** The interiors of A1, A2 and A4 are isoform-invariant, giving unitigs colored
  {201, 202}. A3 and the junction halos A2|A3, A3|A4 are colored {201} only, and the
  A2|A4 junction halo is colored {202} only. The graph branches at the end of A2 and
  rejoins in A4.
- **GENEB.** B1's interior and B3 are colored {201, 202}. The first 36 nt of B2 are
  {201} only. The rest of B2 is shared, except within h_b of the B1|B2 junction, where the
  two isoforms see different upstream sequence. So the shared part of B2 starts about h_b
  after position 36.
- **GENEC / GENECP.** Each substitution splits the shared sequence. Where consecutive
  substitutions are more than about 2·h_b apart, there are paralog-shared unitigs colored
  {C, CP}; near substitutions, gene-specific unitigs. GENEC and GENECP form one family
  (the `spearfish index --mask-genes` threshold, default 20 genes, isn't reached).
- **Families.** {GENEA}, {GENEB}, {GENEC, GENECP}.

The chainer tests use these cases: an exon-skip read (A-202) must score higher on
TOYT0000002 than on TOYT0000001 because of the |A3| = 120 nt target-gap discrepancy, and
vice versa.
