description: How to cite spearfish.
---

A manuscript describing spearfish is in preparation. Until it is available, please cite the
repository:

```bibtex
@software{spearfish,
  title  = {spearfish: fast long-read transcriptome mapping by delta mapping},
  author = {Patro, Rob},
  url    = {https://github.com/COMBINE-lab/spearfish},
  year   = {2026},
}
```
