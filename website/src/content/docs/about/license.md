spearfish is released under the BSD 3-Clause License.

Its test suite builds [lcptools](https://github.com/BilkentCompGen/lcptools) (BSD 3-Clause) as a
reference implementation of locally consistent parsing, to check that spearfish's parser
produces the same core boundaries. lcptools is not part of the spearfish binary.
