## What spearfish does

The isoforms of a gene are built from a shared pool of exons, so a long read is usually
compatible with many transcripts at once. Mappers designed for genomes treat each transcript as
a separate target and repeat the same seeding, chaining and alignment for every isoform that
contains an exon. spearfish does that work once per distinct piece of sequence, and reports, for
each read, every compatible transcript with its position and its score relative to the best.
We call this [delta mapping](concepts/delta-mapping/).
